### Glucose Forecast Dashboard
## A Streamlit web application that predicts short-term blood glucose levels based on recent glucose readings, carbohydrate intake, insulin usage, and physical activity.

# Managing blood glucose levels is a critical part of diabetes care. This project builds a machine learning model and an interactive Streamlit dashboard that allows users to log recent health metrics and receive a short-term glucose prediction.

# The application uses recent glucose values along with contextual inputs such as carbohydrate intake, insulin dosage, and step count to estimate glucose levels in the next hour.
